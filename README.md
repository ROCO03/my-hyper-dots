My personal **Hyprland** configuration, heavily inspired by the [end-4](https://github.com/end-4/dots-hyprland) ecosystem. This repository contains my optimized dotfiles, custom scripts, and aesthetic tweaks.

## ✨ Key Features
* **Window Manager:** Hyprland (Wayland)
* **Status Bar:** Highly customized Waybar
* **Lock Screen:** Hyprlock with custom background
* **Idle Daemon:** Hypridle integration
* **Terminal:** Optimized with custom styling

## 🛠️ Installation
To use these configurations:

1. **Clone the repository:**
   \`\`\`bash
   git clone https://github.com/ROC003/hyper-dots.git ~/.config/hypr
   \`\`\`
2. **Apply:** Restart Hyprland to load the new settings.

## 📂 Repository Structure
* \`hyprland/\`: Core configuration files (keybinds, monitors, rules)
* \`scripts/\`: Essential scripts for theme functionality
* \`custom/\`: Personal style overrides
* \`hyprlock.conf\`: Lock screen styling
